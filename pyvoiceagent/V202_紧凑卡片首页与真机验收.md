# PYVoiceAgent V2.0.2｜紧凑型卡片首页（2026-11-11）

## 根据 iPhone 截图修复的布局问题

V2.0.1 首页采用单列、等高的大卡片，使语音入口不明显，历史/设置等入口需要长距离滚动；下半屏导航被挤出可视区，`finished` 还是开发者英文状态。

V2.0.2 在继续使用 Pythonista **原生 ui** 的前提下优化：
- 顶部只保留软件名称、版本、退出按钮，减少空白。
- 紧凑任务概览卡：最近状态以中文显示，隐藏原始引擎状态字符串。
- 主操作改为使用所选主题色的**整卡语音执行**按钮，手动开始录音、手动点击完成，绝不自动收音。
- 文字任务、处理剪贴板、执行结果、历史档案改为 **两列四卡**；结果按钮直接进入用户友好的结果页，不再把工具日志当首页结果。
- 检查更新及设置与工具改为辅助卡片；底部固定 **首页｜结果｜档案｜设置** 四个入口，保留 iPhone Home Indicator 位置，内容放进可滚动区域。
- 首页、设置、工具库、外观、历史、输入等页面仍调用同一主题调色板：8 套配色、浅色/深色/跟随系统、自定义主题均延续现有用户设置。
- iPhone 窄屏可纵向滚动；主按钮和底栏可点击区域按触摸设计，避免底部操作不可达。

## 保留原有能力

以 V2.0.1 为开发基线，仅改 UI 源码和版本号。保留固定 `PYVoiceAgent.py`、GitHub 更新、DeepSeek、提醒事项、备忘录、苹果日历回调、通讯录、地图原生跳转、BU 期货采集、历史档案、失败保护及用户配置。

正式单文件引擎：`agent_core_2_0_2.py`；可维护 UI 单独副本：`ui_2_0_2.py`（仅源码参考，手机不需要另外安装或导入）。

## 更新步骤

在原脚本的首页点「检查更新」，让旧版本从 `manifest.json` 在线下载安装新引擎；随后退出并重新运行固定入口 `PYVoiceAgent.py`。若自动更新被拒绝，不要删除本机数据或私自覆盖脚本，应先检查清单 SHA 与大小是否一致。

## 手机建议验收

1. 更新并重启，看首页主语音按钮、四张常用卡、底栏是否全程无重叠。
2. 点击底栏“结果”，确认卡片结果可以查看；点击完成返回首页。
3. 点击底栏“档案”“设置”，再点“首页”，确认不进入控制台。
4. 切换紫色/橙色、浅/深色确认页面同步换色；返回后主题不丢失。
5. 尝试手动语音、文字、日历查询回调、地图跳转，确认旧功能未受影响。
