# PYVoiceAgent V1.9.4 — 统一结果中心（2026-11-10）

以正式 V1.9.3 为基线，原有入口、DeepSeek、语音、提醒、日历、备忘录、通讯录、网址、BU 行情、GitHub 更新程序均保持原模块/路由不变。

## 这版解决的问题

- **自动归档**：每个普通任务按唯一任务 ID 保存 JSON 和 Markdown，不再只依赖会被新任务覆盖的 current_task.json。新任务不覆盖旧任务；同一任务的各状态变更会更新该任务专属档案。
- **旧数据尽量迁入**：新引擎首次启动会把旧 current_task.json（如果存在有效 ID）迁入档案。之前已被覆盖的历史无法恢复。
- **统一搜索**：首页「历史档案」搜索本机 AI 任务及原有 bu_futures 目录内的 BU 日/夜盘快照。不会复制价格到第二套库。
- **详情与导出**：点击历史卡片查看最终文本、逐工具日志。支持「复制全文」到剪贴板、「分享／导出」Markdown（BU 直接导出原 TXT）。
- **核验分级**：区分本机完成、系统读回核验、快捷指令报告成功但未独立核验、等待回调、人工核验及失败；不把一次 ok 回调当成苹果备忘录或日历已独立核验。
- **工具就绪状态**：工具库区分已授权候选与未配置/未验收。自定义快捷指令仍须用户登记及真机核验。

## 手机上的位置

继续运行固定 PYVoiceAgent.py，进入卡片首页 **「历史档案」**。输入“金陵”“BU2612”“合同”等关键词，可搜索本机归档。

本机存储目录：

- Pythonista3/Documents/PYVoiceAgent_Data/history/YYYY-MM/task_任务ID.json
- Pythonista3/Documents/PYVoiceAgent_Data/history/YYYY-MM/task_任务ID.md

原有行情文件仍位于 Pythonista3/Documents/PYVoiceAgent_Data/bu_futures，不移动、不覆盖。

**隐私说明：** 档案可能含客户信息、剪贴板及报价；不会上传 GitHub，但在本机以明文保存，应保护手机访问权限并按需备份。API Key 和快捷指令回调 Token 不会写入新增的归档字段。

## 升级与验收

仍沿用固定 PYVoiceAgent.py 入口和 GitHub 在线更新。升级后退出并重新打开；旧桌面语音入口、PYAgentCalendar、PYAgentNotes 和 BU 日夜盘定时自动化链接不需更改。

1. 文字输入“请整理今日沥青报价：金陵6100、镇海6240”，查看结果是否进入历史档案。
2. 再执行另一项任务，检查上一份结果是否仍可搜索、复制和分享。
3. 搜索 BU2612，打开之前保存的 BU 行情文件。
4. 在「设置与工具 → 工具库」查看未验收的日历、备忘录是否正确标记。
5. 如涉及系统写入，回调成功之后仍要到苹果 App 检查项目确实存在。

## 测试和限制

独立归档模块本地 20 项单元测试通过；仓库新增完整核心编译、14 项整合检查和 BU/日历既有功能回归的 GitHub CI 工作流。CI 实际执行结果与 iPhone 真机状态要分别核验；不能混同。

搜索最多扫描最近 1600 条文件，并展示最多 75 条。旧引擎的 AI 单项文字输出上限及 iOS 锁屏后台限制尚未改变。

档案保存在手机设备上，删除 App 或丢失设备资料仍可能导致文件丢失；程序更新不会自动清除它，但本地保存不能代替备份。
