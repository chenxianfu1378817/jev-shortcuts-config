# PYVoiceAgent V1.5 — iPhone 一次性系统模块配置

> 仅在 V1.5 开发引擎通过检查并准备真机验收后按此文件操作。**不要现在修改 V1.4.3 的 PYAgentHub。**

## 为什么不是“从菜单中选取”

苹果快捷指令的“从菜单中选取”需要用户交互；不能把 DeepSeek 传入的 route 当成自动菜单选项。V1.5 在 Python 中有固定白名单映射，自动调用对应的快捷指令名称，不需要你每次点菜单。

| 工具 route | Pythonista 直接执行? | iOS 执行模块 |
| --- | --- | --- |
| reminder.create | 是 | 不需要 |
| local_note.save | 是 | 不需要 |
| apple_notes.create | 否 | PYAgentNotes |
| calendar.create | 否 | PYAgentCalendar |
| shortcut.hub_echo | 不执行系统写入 | 沿用原 PYAgentHub |

## 通用输入格式

Pythonista 通过 `shortcuts://run-shortcut?name=模块名称&input=text&text=...` 传入 **Base64 编码的 JSON 文本**。关键字段：

- `route`：固定路由（`apple_notes.create` 或 `calendar.create`）。
- `token`：随机回调令牌（不要自己生成）。
- `title`：事项标题。
- `note_body`：苹果备忘录实际写入的干净正文（首行已经包含标题）。
- `start`、`end`：带时区的 ISO 8601 时间；日历模块使用。
- `notes`：日历备注。**不要把 marker 字段写到用户内容中。**
- `marker`：只供 Pythonista 本地诊断留存。快捷指令无需使用。

### 两个模块通用的前置动作

1. 新建对应名称的快捷指令，打开编辑页面。
2. 加一个“Base64 编码”动作，输入选择**快捷指令输入**，把模式切换为**解码**。
3. 将解码结果转换成文本，并用“从输入中获取字典”或类似名称的 JSON/字典动作得到“任务词典”。不同 iOS 版本中文动作名称可能略有变化。
4. 用“获取字典值”分别读取 `route`、`token` 和相应业务字段；如判断条件只显示“有任何值/没有值”，先用“文本”动作插入 route，再让“如果”比较这份文本。

### PYAgentNotes — 创建苹果备忘录

1. 检查 route 的文本**等于** `apple_notes.create`；其他值不执行。
2. 读取键 `note_body`，用苹果“创建备忘录”动作写入，关闭会阻止自动完成的编辑确认界面（若该动作提供此选项）。不得把 `marker` 或 token 拼到正文。
3. **只在“创建备忘录”确实返回新建的备忘录对象之后**，继续构造成功回调 URL。否则不发送 `ok`。
4. “文本”动作写入回调地址，蓝色变量必须使用任务词典取出的 `token`，而不是字面上的 token：

   `pythonista3://iCloud/PYVoiceAgent.py?action=run&argv=bridge_callback&argv=【token变量】&argv=ok`

5. 使用“打开 URL”动作执行回调，随后“停止并输出”。未执行写入时不能发送 `ok`。

### PYAgentCalendar — 创建日历事件

1. 检查 route 文本**等于** `calendar.create`；其他值不执行。
2. 从任务词典读取 `title`、`start`、`end`、`notes`、`token`。
3. 使用快捷指令日期解析动作把 `start` / `end` 转成日期，检查结束晚于开始，保留源时间中的时区语义。首次实际验收时特别核对显示的日期、时分。
4. 调用“添加新日程/添加日历事件”（具体名称可能因系统而异），填入标题、开始、结束和用户备注，尽量关闭额外编辑界面。
5. 仅在添加动作返回事件对象之后，按与 PYAgentNotes 相同的方法构造回调 URL。不能仅因跳转到日历 App 就发送 `ok`。

## 一次性启用（不需要手动编辑 JSON）

1. 先在快捷指令 App 新建上述独立模块；**不要删除原来的 PYAgentHub**。
2. 打开新版 Pythonista 固定入口，进入菜单 **17. 首次安装/验证系统模块**。
3. 选择一个模块，允许执行一次带“模块验收测试”标题的真实写入。
4. Pythonista 收到带原 token 的 `ok` 后，会询问你**是否在对应的苹果 App 里亲自检查到测试项目**。只有选择“已经确认存在”，程序才会登记为可用模块。
5. 每个模块只需首次启用一次；以后 DeepSeek 自动选择执行路径。验收用的测试项目可以手动删除。

## 安全与真实验收边界

- 快捷指令回调 `ok` 只表示它报告成功。首次人工检查后才允许模块启用，普通使用的回调报告与独立读回必须区分。
- 没有安装或验证的模块，V1.5 应报告“功能未就绪，未执行”，不会调用不存在的快捷指令。
- 写入可能已发生但未收到回调时，应归档为待核验，禁止自动重放同标题的事项；其他不相关任务可以继续。
- 当前方案无法无条件自动读出苹果备忘录全部内部信息，也不能绕过 iOS 权限、系统确认或控制任意 App UI。
- 操作失败或没有返回对象的 Shortcut，不要在“否则”分支放无条件 `ok` 回调。
