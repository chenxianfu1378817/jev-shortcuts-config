# PYVoiceAgent V2.2.2｜修复更新校验失败与 iPhone 导航遮挡（2026-11-11）

## 已从真实截图确认的根因

- iPhone 运行 V2.1.0 时点击「检查在线更新」，收到「版本清单未通过安全校验」。
- V2.1.0 引擎中的 `MAX_UPDATE_BYTES=350000` 是更新安全机制的硬限制。
- 之前发布的 V2.2.1 引擎大小 **371,889 字节**，高于旧版上限，故即使 SHA-256 正确也会被旧版拒绝。错误在于发布兼容性检查未覆盖旧版上限；**不是网络异常，不能通过取消哈希或放宽验证来绕过**。
- 截图显示 V2.1.0 首页标题与系统状态栏重叠；底部菜单滚动后不可见。

## V2.2.2 技术修复

- 保留 V2.2.1 的持续本地 WebView 对话、任务后台执行、手动语音开始/结束/取消、AI 追问、授权、历史、主题、原版系统接口与数据保护。
- 删除已被持续对话主页取代的**重复旧版单次 WebView 页面及专属桥接代码**，不会删改原任务引擎。保留原生 Pythonista `ui` 回退，以免新版 WebView 不可用时失去操作能力。
- 新版本完整引擎文件压缩到 **346,626 字节**，低于原更新器的 **350,000 字节上限**；不修改旧手机的更新代码，不取消 SHA-256 或尺寸限制。
- 新对话页顶部增加最小 68px 的 iOS 状态栏安全留白；顶部「对话｜历史｜设置」切换保留在独立固定区域，而非随聊天消息滚动；底部输入区增加安全留白，独立的录音控制保留。
- 兼容旧启动入口 `PYVoiceAgent.py`、既有快捷指令 `argv=voice`、`argv=text`、系统回调及在线升级引擎路径；数据目录、主题、历史记录和 API Key 不覆盖。

## 代码与测试边界

## 手机上怎么更新

V2.1.0 的原「检查在线更新」应该可以直接接收 V2.2.2，因为新发布文件小于它的固定上限。**无需卸载 Pythonista、重新下载 ZIP 或改变固定入口。**

更新成功后，关闭并重新运行 `PYVoiceAgent.py`，确认顶部为 V2.2.2；先测试「我要点外卖 → 快餐」、语音开始/取消、历史与设置页切换，不要先批量创建真实日历或提醒。若更新仍失败，保留错误全文与版本号，检查缓存与实际远程清单，不覆盖用户数据。
