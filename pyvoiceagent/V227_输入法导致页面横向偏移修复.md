# PYVoiceAgent V2.2.7｜修复输入文字后整个页面横向偏移

发布日期：2026-11-11。基线：V2.2.6。

## 真机截图与根因分析

用户在 Pythonista 本地 WebView 的持续对话窗口点击输入框、输入文字并提交之后，整个助手页面在横向向右偏移约半屏，左侧大片空白、右边菜单和输入框被屏幕裁切。V2.2.6 的 HTML 使用 `#app{position:fixed;left:50%;transform:translateX(-50%)}` 居中，同时在软键盘焦点变化时动态设置 `height/top`，且没有对文档和内容区显式禁止横向滚动。这组定位在 iOS WebView 的焦点/视口变化时存在不稳定风险。此次根据实际截图针对性修复，未改动任务规划、DeepSeek 或苹果系统业务工具。

## V2.2.7 修复

- 改为固定页面 `top:0;left:0;right:0;width:100%`，去掉 `left:50%` 与 `translateX(-50%)` 居中变换，避免视觉视口变化时整个页面水平位移。
- 在 HTML `html/body` 及独立消息滚动容器禁止横向溢出，保留消息卡片和文字自动换行。
- 输入框失去焦点和视口恢复正常高度后，清除横向滚动偏移、恢复 WebView 左侧原点；发送后再于键盘动画阶段执行一次布局核验。
- 原有 iPhone 安全区域、中文拼音选字、多行输入、主动收起键盘、固定底部按钮、历史与设置、退出按钮和快捷指令工具库均保留。
- 源码不再依赖 CSS transform 进行手机主容器定位，使用更稳妥的全宽固定布局。

## 更新与验收

打开固定入口 `PYVoiceAgent.py`，进入「设置 → 检查在线更新」，安装 **V2.2.7** 后退出并重新打开。先只测试文本“你好”：点底部输入框，输入并发送，观察文字界面是否仍占满整个手机宽度，顶部三个菜单、输入框和发送按钮是否完整；再测试多行输入、收起键盘、退出、快捷指令工具库。若界面已经偏移到无法点设置，先关闭当前运行的 Pythonista WebView，再通过固定入口重启并更新，不清理任何历史或配置。若仍偏移，保留完整截图和触发步骤用于进一步诊断。
