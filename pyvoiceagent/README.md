## V2.3.7｜语音闪退止损：改用苹果键盘听写（2026-11-11）

- **已确认的用户问题**：V2.3.6 点击语音即退出 Pythonista，说明将 `sound.Recorder` 移入后台工作线程并未通过手机验收。由于尚未得到可定位 C/Objective-C 崩溃源的完整报告，本次**不再宣称修好原生录音**。
- **安全回退方案**：聊天界面的「🎙」按钮**直接激活输入框/键盘**，不再从按钮调用 `sound.Recorder`、`speech.recognize` 或原生录音工作线程。用户再点 iPhone 系统键盘上的麦克风听写，说完点键盘麦克风结束，检查文字，点「发送」；照常进入 DeepSeek/本地 Agent 任务执行。
- **兼容全部旧入口**：桌面 `argv=voice`、传统菜单语音与 AI 追问语音入口改用系统输入框听写，按完成提交文字；空白或取消不会启动任务。程序内部仍保留实验性音频服务模块作为源代码研究对象，但正式界面没有可到达的原生录音调用路径。
- **原功能和安全不变量**：固定 `PYVoiceAgent.py`、所有模块化源码、日历/提醒/快捷指令、历史、八主题、GitHub 在线更新和用户数据保留。引擎字节数、SHA-256 由发布清单核验；**不删除手机本地资料**。
- 系统听写需要「设置 → 通用 → 键盘 → 启用听写」，不同语言和地区支持可能不同。用户在启动语音时会多一次键盘麦克风点击；**这是一项临时安全替代，不等于恢复原来的单击开始/结束录音**。
- GitHub 模拟回归包含聊天麦克风不会调用 `sound.Recorder`、旧语音入口不触发原生录音、空输入不创建任务、主要业务入口仍存在。**未做 iPhone 真机验收。**若使用文字或系统听写仍直接崩溃，应继续采集 `callback_last_error.json` 或脱敏 iOS .ips，暂停重复尝试。

## V2.3.5｜快捷指令安全与 Pythonista 回调崩溃保护（2026-11-11）

- **针对真机记录的异常堆栈**：聊天 `ui.delay` 回调和原生快捷指令工具库工作线程发生 Python 异常时，做边界捕获与本机脱敏记录，避免未处理异常直接进入 Pythonista 事后调试器。无法保证拦截 C/Objective-C 原生 SIGSEGV。

- **保护任务及个人数据**：任务状态损坏时不视作空白；存在未完成、待回传或待核验任务时禁止变更登记库。历史记录、快捷指令、主题、DeepSeek Keychain、日历和提醒任务不迁移或删除。
- 保留 V2.3.4 手动停止录音的工作线程、原生工具库、持续聊天、八套主题和原 `PYVoiceAgent.py` 入口。引擎 348665 字节，保持旧版更新器 350000 字节上限；发布清单严格校验长度及 SHA-256。
- GitHub 自动测试覆盖回调异常、并发 JSON/注册表写入、损坏任务拒绝修改、失败回滚和旧功能。**不是手机真机测试**；请用无系统写入的测试快捷指令检查“打开工具库 → 新建 → 编辑 → 返回”，另外单独测试麦克风停止。若仍退出，可检查本机 `PYVoiceAgent_Data/callback_last_error.json`；原始用户文本和 API Key 不会写入此诊断。
- 更新：运行固定 `PYVoiceAgent.py` → 检查在线更新 → 安装 V2.3.5 → 退出并重新启动。不要重复创建日程或提醒来测试。
