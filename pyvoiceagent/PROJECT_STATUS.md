## 2. 最新功能状态（GitHub 已包含，不等于 iPhone 实测成功）

- **V2.2.0–2.2.1**：持续对话式 WebView，正常结果显示在 App 卡片内；传统功能仍可调用。
- **V2.2.3**：第二次点击麦克风停止录音的原生闪退风险已做异步生命周期保护；用户坚持**手动开始、手动停止录音**，不可偷偷恢复自动收音。
- **V2.2.4**：按可见视口适配输入框、中文拼音输入、多行文本、键盘收起与聊天滚动。
- **V2.2.5–2.2.6**：顶部退出按钮；设置中的**本地快捷指令工具库**支持注册/编辑/启停/删除、别名、参数、执行前确认、本地优先/DeepSeek 白名单调用；再次检查暂停/待回调任务，不覆盖旧任务状态。
- **V2.2.7**：移除可能导致键盘弹出后整页横向偏移的 `left:50%` + `translateX(-50%)` 主容器定位，约束横向滚动并在发送后恢复布局。
- **长期保留**：8 套主题、浅/深/系统模式、卡片统一设计；日历/提醒/备忘录/通讯录、BU 行情与日历归档、地图原生唤起、历史结果、DeepSeek、AppRouter、桥接回传、固定入口与 GitHub 校验更新。

## 5. 数据保护、不变量与发布规范

1. 任何时候都**保留** `~/Documents/PYVoiceAgent_Data/` 下真实用户数据，尤其是 `current_task.json`、`shortcut_registry.json`、主题配置、历史记录、DeepSeek 配置及独立业务台账；更新器不可覆盖。
2. 真实或可能真实的“待人工核验 / 待回调 / 暂停 / 正在写入”任务，不自动清理、不强制重做、不因登记快捷指令覆盖。
3. 不将 API Key、录音、电话号码、通讯录或个人记录写入公开仓库。密钥优先系统安全存储。
4. 所有页面遵循统一卡片设计，8 套主题与浅色/深色/跟随系统同步生效，适配 iPhone 键盘、安全区和动态视口。
5. 在线更新遵守旧启动器安全上限、SHA-256、语法检查、失败恢复及用户数据分离；不要通过放宽验证来掩盖超出文件大小。
6. 每次**代码**升级必须递增正式版本与 `sequence`，同步引擎、`manifest.json`、README、测试和本文件；文档编辑**无需**虚构新软件版本。
7. 单元测试/模拟测试/CI 与 iPhone 真机测试分别报告。发布后需远端核对 `manifest` 与源码一致才可称 GitHub 发布完成。
