# PYVoiceAgent V1.8.2｜本地快速路由 + 自动交给 DeepSeek

## 本次已实现
- **保留一个背面双击入口**：`iCloud/PYVoiceAgent.py`，不修改 Pythonista 快捷指令、URL Scheme、原五项首页。
- **新增本地指令识别器**：对单步骤、明确、高置信度的22种 App 功能，识别 App/操作/关键词；使用现有 `PYAgentAppRouter`，**不调用 DeepSeek，0 DeepSeek Token**。
- **自动交接**：规则没匹配、请求多步骤/条件判断/总结、或 AppRouter 未启用时，进入现有受控 DeepSeek 规划流程；不需要用户手动挑选引擎。
- **缺少参数**：例如“抖音搜索”，本地直接提示补充关键词，不乱猜。
- **跨 App 跳转**：先写本地任务状态/请求记录，再交给 iOS。实际页面是否打开，仍需真机确认；不声称获取到抖音/微信等 App 内的数据。
- **旧能力保留**：V1.8.1 微信剪贴板联系人→通讯录（纯本地、需确认、号码去重）；PYAgentCalendarRead 回调；calendar.assist（读取真实日程后再 AI 分析，可经确认创建提醒事项）；备忘录、日历、提醒、剪贴板、通讯录、AppRouter22项和 V1.7.9 快捷指令生成器。原来的五项首页不变。

## 技术核心
- `_local_quick_intent(goal)` 是纯函数；返回 `LOCAL`、`CLARIFY` 或 `None`。
- `None` 自动交给 V1.8.1 已有 DeepSeek 规划器，保留权限和参数检查。
- `_local_fast_execute()` 复用 `parse_decision()`、`available_tool_catalog()`、`execute_planned_actions()` 及 `_app_route_target()` 原白名单，而不是另建不受控 URL 执行器。
- 当前有等待回调、待核验或写入中的任务时，禁止本地跳转覆盖原任务。
- 只匹配**完整单步骤表述**，例如仅提到“抖音”和“沥青”不足以执行。含“不要、然后、如果、总结、分析、发送、付款”等表达自动回退 AI。
- 本地引擎只做只读/导航动作，不创建提醒、不新增通讯录、不发消息、不修改 VPN；已有联系人入库仍使用独立验证的安全路径。
- 本地跳转前保存状态，支持 iOS 切换 App 时的中断，但不把无回调的 App 页面跳转当成任务执行成功。

## 适用边界
- **不是任意多 App 无人值守控制**。苹果应用内部不公开的数据不能只靠 URL Scheme 读取；抖音搜索并不等于拿到视频字幕和内容。
- **多步骤的结果依赖**当前已能用于受限的日历→分析→建议或待办，以及公开网页→分析等已授权工作流；不能把缺接口的任何任务都承诺自动完成。
- 用户语音经过 iOS 语音识别；0 Token 指**没有 DeepSeek API 调用**，不是苹果语音识别必然离线。
- 目前只有 GitHub CI 模拟测试通过，iOS 27 真机需要用户更新后按上面四个场景测试；旧版已验收的 App 路由保持兼容。
