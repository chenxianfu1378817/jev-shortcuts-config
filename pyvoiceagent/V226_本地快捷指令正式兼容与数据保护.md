# PYVoiceAgent V2.2.6｜快捷指令 Agent 工具库正式兼容版

基于 V2.2.4 的完整业务引擎，提供 V2.2.5 的退出助手按钮、本地快捷指令登记/编辑/启停/删除、自然语言触发和 AI 白名单调用，并新增旧任务保护。

**新增数据保护**：若旧任务为 `awaiting_callback`、`needs_review`、`running`、`writing`、`paused`、`needs_input` 或 `replan_pending`，新快捷指令不得覆盖 `current_task.json`；用户确认后、即将唤起 iOS 快捷指令之前，再检查一次状态，防止异步等待期间旧任务变化。防止暂停中的日历/提醒操作丢失或被误重放。

## 操作

从固定脚本 `PYVoiceAgent.py` 的「设置 → 检查在线更新」升级 V2.2.6，退出后重新运行。顶部新增「退出」按钮，返回 Pythonista 而非强制杀死 Pythonista 宿主。打开「设置 → 我的快捷指令工具库」可以登记本机 Shortcut 名称、别名、执行方式、传参、是否确认，并查看、修改、启停和删除。

自然语言明确匹配已登记的快捷指令时本地执行，0 次 DeepSeek 请求；其他任务仍可由 AI 选择本地已启用的白名单 ID。**普通直接启动只表示发送了启动请求，不能证明内部操作完成**；需要结构化结果和安全回传时选择回传模式，并在该快捷指令内部配置原有 token 回传流程。注册本身不能验证真实 Shortcut 是否已安装。

本机配置保存在 `PYVoiceAgent_Data/shortcut_registry.json`，升级不覆盖；兼容原来只有名称和描述的登记信息。旧版引擎和恢复备份由既有更新器保护，不改入口、不覆盖 API Key、历史任务与主题。
