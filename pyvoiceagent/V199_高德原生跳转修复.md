# PYVoiceAgent V1.9.9｜高德地图原生 App 跳转修复

## 修复原因
旧版 `amap_search` 使用 `https://uri.amap.com/search?callnative=1`：它是网页链接，可能停留在浏览器，不保证进入高德地图 App。

## 新行为
- 语音说「帮我打开高德导航去民歌湖」或「高德地图搜索民歌湖」，程序优先通过本机规则识别，不需要 DeepSeek 规划。
- 改为官方 iOS App Scheme：`iosamap://poi?sourceApplication=PYVoiceAgent&dev=0&name=...`，参数自动做 URL 编码。
- Pythonista 在前台直接调用 `shortcuts.open_url(iosamap_uri)`，不再经过 HTTPS，也无需旧的 `PYAgentAppRouter` 中转。
- 如果唤起失败，会提示请求失败，不自动弹网页，也不会宣称已完成导航。
- 如果只提供「民歌湖」这样的名称，没有唯一的 POI ID/可信终点坐标，**只会打开高德 App 的地点搜索结果**；用户需选中正确地点并点击「导航」。不会编造坐标或自动选择可能错误的停车场入口。
- 微信、百度地图等原有第三方 App 路由继续通过 PYAgentAppRouter，未改动。
- 桌面语音快捷指令、固定入口 `PYVoiceAgent.py`、手动结束录音、DeepSeek、BU 行情、日历和历史档案原样保留。

## 不需要重新设置参数或下载文件
在手机上检查在线更新至 V1.9.9 后退出并重新打开。
原语音快捷指令 URL 不变：
`pythonista3://iCloud/PYVoiceAgent.py?action=run&argv=voice`

无需高德 API Key，但必须先安装高德地图 App。iOS 对自定义 URL 协议的具体唤起行为仍需在实际 iPhone 上验收。

## 可直接检查原生协议
在 iPhone 快捷指令中，如果想独立诊断，只要「URL」→「打开 URL」，内容为：

`iosamap://poi?sourceApplication=PYVoiceAgent&dev=0&name=%E6%B0%91%E6%AD%8C%E6%B9%96`

这条链接只应打开高德地图 App 的「民歌湖」搜索结果，不是自动开始实时驾车导航。
