# PYVoiceAgent V2.2.4｜iPhone 键盘遮挡及对话输入优化（2026-11-11）

## 从真实截图定位的问题

点击底部文字输入框后，iOS 拼音键盘和 Pythonista 原生输入工具栏占据屏幕下半部分。旧 WebView 页面写死 `height:100dvh`，**没有监听 iOS VisualViewport 变化**，导致底部输入栏被遮挡，聊天内容没有随键盘重新分配空间。

另外旧 JS `send()` 先本地插入一次用户气泡，Python 在 `submit()` 又回传同样内容，造成一条消息可能显示两次；中文拼音候选阶段按回车还可能被当成“发送”。

## V2.2.4 功能与界面

- 使用 `window.visualViewport` 的 `resize`、`scroll` 事件和 `window.resize`，根据实时可见高度调整 WebView 的主容器，聊天记录在剩余空间内滚动，输入栏随键盘移动到可见区域。
- 输入时顶部标题/标签栏压缩但保持可见；隐藏底部快捷按钮和重复提示，腾出空间给多行文字输入及发送按钮。
- 独立“⌄ 收起键盘”按钮，发送后自动收起键盘，恢复完整对话区域。iOS/Pythonista 自带的键盘工具栏（包括 Done）可能仍然显示，该工具栏不属于 HTML 界面，不能承诺移除。
- 输入框字体升为 16px 避免 iOS 自动页面缩放；随着输入文本自动扩展至 110px，适合多行指令。
- 中文拼音组词时的回车不提交；发送按钮承担手机的主要提交操作，桌面键盘可用 Ctrl/Cmd + Enter 发送。
- 删除 JS 的乐观重复消息显示，只由已接收的 Python 后端回传生成用户气泡；不改动 Python 原任务与历史保存逻辑。
- 继续保留 V2.2.3 手动录音开始/结束/取消、语音识别线程防护、DeepSeek、日历、提醒、BU、快捷指令回调和多主题。

## 使用与限制

在手机原入口 `PYVoiceAgent.py` 的「设置 → 检查在线更新」升级 V2.2.4，退出后重新运行。请点输入框测试：拼音输入→换行→点击紫色发送按钮，观察键盘能否收起，聊天内容、底部输入框和顶部导航是否正常。

**模拟测试不等于 iPhone 真机测试。** 不同 iOS/Pythonista 版本的 WKWebView 键盘尺寸回调可能不同；若仍出现遮挡，请保留新版本屏幕截图，不要批量试验日历/提醒写入任务。
