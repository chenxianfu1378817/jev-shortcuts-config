# PYVoiceAgent V1.8.1｜微信姓名、单位、电话 → 苹果通讯录

## 日常使用（不需要新建或签名苹果快捷指令）
1. 在微信聊天中选择并复制**一个人**的姓名、单位、手机号。建议格式：
   ```
   姓名：张三
   单位：广西某道路工程有限公司
   手机：13800138000
   ```
2. 用原来的 `PYVoiceAgent.py` 首页「立即更新版本」升级到 **V1.8.1**，不修改桌面入口、Hub 或原有快捷指令。
3. 运行「语音执行任务」，说：“**把刚复制的联系人保存到通讯录**”；或者在「文字／剪贴板任务」中选择新增的「**剪贴板→新增通讯录联系人**」。
4. 系统在**本机**识别并显示姓名/单位/完整号码，点击一次「保存」后，写入苹果通讯录，读回相同姓名、单位及手机号码验证。请首次授权 Pythonista 访问通讯录。若缺少权限，打开系统设置中 Pythonista 的通讯录权限。
5. 不需要 DeepSeek API；录入过程不上传剪贴板、号码、姓名或通讯录给 DeepSeek。

## 支持的格式
- 分行：`姓名：张三\n单位：广西XX集团\n电话：13800138000`
- 同行：`姓名:张三，单位:广西XX集团，手机:+86 138 0013 8000`
- 三行无标签（结构明确时）：`张三\n广西XX集团\n13800138000`
- 单行简单格式（组织名称可识别时）：`张三 广西XX集团 13800138000`
- 仅姓名和手机号：`姓名：张三\n电话：13800138000`（单位为空）
- 同一号码重复出现在同一条文本中，识别为一个号码。

## 本版有意限制
- **仅支持中国大陆11位手机号码**，包括明确的 +86/0086 前缀和常见空格、短横线。固话、国际号码、多个不同手机号不自动保存。
- 一次只新增一个联系人；整段聊天、模糊姓名、聊天寒暄、含外部链接或过长的复制内容会提示重新复制，不猜测姓名、单位。
- 检查 Pythonista **可访问的通讯录**中相同手机号码，发现则不重复新增；同姓名但号码不同也暂停，交由用户人工判断。iOS 可能采用受限通讯录权限，因此检查范围取决于授权。
- 保存前一次弹窗核对。此版本**不覆盖/修改已有联系人**，也不自动批量新增。
- 写入意图保存在 Pythonista 本地防重账本，不保存完整电话到账本；异常时禁止重试。手工确认已保存后可自行在通讯录里核查。
- “查看上次执行结果”的旧主任务记录不被覆盖；本功能单独将脱敏执行结果保存在 `~/Documents/PYVoiceAgent_Data/clipboard_contact_last.json`。
- iOS 27 的实际通讯录读写权限、同步时延与账户设置需要用户设备验收。保存成功的标准是系统写入**且**从可访问通讯录读回准确姓名、单位、手机号码。

## 原有功能保持不变
- 原五项首页；Pythonista 固定入口 `PYVoiceAgent.py`；升级流程；PYAgentHub；PYAgentAppRouter（22项）；PYAgentCalendarRead；备忘录、日历、提醒事项；DeepSeek 密钥配置。
- 原有“2. 使用剪贴板内容”的文本分析功能不变。只有用户明确说“复制/剪贴板/微信 + 通讯录/联系人 + 保存/录入/新增”等，才进入本地通讯录写入通道。
