# iPhone 原生快捷指令：完全离线中国大陆工作日判断（不安装 Pythonista）

这不是运行 Python 或 JavaScript，而是用苹果内置的词典动作查询预先生成的365天日历。

## 准备

- 2026年日历：`offline_2026_shortcuts.json`（365个 yyyy-MM-dd 日期键，对应数字 1=工作日、0=休息日）。
- 2026年放假及调休补班依据：国务院办公厅 国办发明电〔2025〕7号，https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm 。
- 在添加到快捷指令时，手动复制 JSON 内容到一个「文本」动作；以后运行完全离线。通过隔空投送把文件传给无代理手机也可以。

## 快捷指令配置（所有动作均为系统自带）

1. 【当前日期】（可在调试时暂时改成「日期」：2026-10-26）。
2. 【格式化日期】：输入第1步的日期；格式选“自定”，填写 `yyyy-MM-dd`。
3. 【文本】：一次性粘贴文件 `offline_2026_shortcuts.json` 的**全部 JSON 内容**，包括首尾大括号。
4. 【从输入中获取词典】：输入设为第3步文本。
5. 【获取词典值】：从第4步词典中，取键为第2步格式化日期的值。
6. 【如果】：第5步的值**等于 1**，放入你需要执行的任务；【否则】不执行。

2026年10月25日 -> 0；10月26日 -> 1；10月10日（周六补班）-> 1。
这里的 0 只是离线词典里的数据；最后仍然**只在结果为1时执行任务**。

## 年度边界和安全

目前仅2026年有完整日历。2027年没有相应键，未取到1时一律不执行；不要以“结果不等于0”作为执行条件。真正离线运行不可能自动下载下一年国务院公告，因此需要在2027年开始前把审核通过的新年 JSON 表重新嵌入到每部手机的文本动作里。与之相对，云端 Worker 可由 GitHub Actions 自动更新，但调用它需要网络。

注意原生 iOS「在网页上运行JavaScript」动作需要从 Safari 分享网页，不能替代无人值守的离线工作日判断。
